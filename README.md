# 💻 BMI Calculator
A responsive web application that calculates a person's BMI through the user providing their gender, age, height and weight. Built with basic HTML, CSS and JavaScript.

## 🔧 Technologies
- HTML
- CSS
- Javascript

## ✨ Features
- Input fields that allow users to select their gender, as well as enter their age, weight and height
- Calculates and displays a persons BMI once input fields are all correctly entered
- Validation to check if all fields are filled with valid inputs else error modal pops up.
- Mobile responsive design,

## 🎈 The Process
I wanted to create a simple web application to practice some of my foundational frontend development skills (HTML, CSS, JavaScript). I decided to do a BMI calculator because I wanted to do some Javascript, the creation of input fields will help me develop my DOM skills. I created the main HTML layout first then styled everything with CSS and made sure that the app was mobile responsive. Then I implemented the Javascript logic and DOM for calculating the BMI.
